# Generic Landing Page

A clean and responsive landing page built with semantic HTML5 and modern CSS (Flexbox).

## 📖 About The Project

This project is part of my journey learning full-stack JavaScript through **[The Odin Project](https://www.theodinproject.com/)** curriculum. 

The goal of this project is to build a complete landing page from scratch based on a provided design mockup, focusing on mastering HTML structure and CSS Flexbox layout techniques.

## ✨ Features

- **Navigation Header:** Clean top navigation bar with a logo and navigation links.
- **Hero Section:** High-impact introduction area with headline, subtext, call-to-action button, and image placeholder.
- **Information / Features Section:** 4-column card grid highlighting key features with illustrations and descriptions.
- **Testimonial / Quote Section:** Styled quote card block with custom typography.
- **Call to Action (CTA) Banner:** Highlighted signup container prompting user action.

## 🛠️ Built With

- **HTML5** – Semantic page structure
- **CSS3** – Modern Flexbox layout, Google Fonts (*Roboto*), custom styling and buttons
